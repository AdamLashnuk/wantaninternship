# WantanInternship

A polished, searchable directory of internship job boards, GitHub repositories, startup platforms, government portals, and research programs.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import the repository into Vercel. No environment variables or database are required for this MVP.

## Customize

- Edit resource listings in `data/resources.ts`
- Change homepage content in `app/page.tsx`
- Change visual styling in `app/globals.css`
